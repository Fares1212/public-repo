# Fortnite chest icon

`fortnite-chest.png` is the original, unmodified transparent 32 × 32 PNG chest
icon used by the Fortnite chest map in
[radekrepka/fortniteclub](https://gitlab.com/radekrepka/fortniteclub).

- [Source file at the retrieved commit](https://gitlab.com/radekrepka/fortniteclub/-/blob/be93746a1463562feb4034cd4cd317f3e316b575/www/assets/images/web/loot_icon.png)
- [Fortnite chest map using this icon](https://gitlab.com/radekrepka/fortniteclub/-/blob/be93746a1463562feb4034cd4cd317f3e316b575/app/templates/ChestsMap/default.latte)

Fortnite and its chest artwork belong to Epic Games. This fan-made counter is
not affiliated with or endorsed by Epic Games. The image is bundled locally;
the counter does not download images or connect to Fortnite at runtime.
